# Voice system

## Positioning line
Keep the structure. Lose the identity.

## Primary hero
Pseudonymize sensitive data without breaking your workflow.

## Supporting
Detect and replace personal identifiers across text, datasets and files with consistent pseudonyms, so your data stays usable while real identities stay out of the way.

## Product microcopy
- Run pseudonymization
- Review detected entities
- Export pseudonymized file
- Mapping access restricted
- 4 entities replaced
- Review required

## Error language
State what failed, what was affected, and what the user can do.
Bad: `Something went wrong.`
Good: `The file could not be processed. No output was created. Retry or upload a CSV under 100 MB.`
