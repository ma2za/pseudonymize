# pseudonymize.io visual identity v2

Production-oriented identity and UI starter kit.

## Preview
Open `web/index.html`, `web/app.html`, `web/docs.html`, and `email/job-complete.html` in a browser. Rendered PNG previews are in `previews/`.

## Production assets
- `logo/` SVG identity variants
- `favicons/` favicon and app-icon set
- `tokens/` JSON, CSS and Tailwind-ready theme
- `components/COMPONENT-SPEC.md`
- `docs/` accessibility, voice and trust-copy rules
- `social/` OG and GitHub preview templates
- `graphics/` transformation grammar

## Implementation note
The package specifies Inter and IBM Plex Mono but does not distribute font files. Install or serve those fonts separately, or use the included fallbacks.

## Security note
All security/trust claims in the demo are placeholders unless they describe UI behavior visible in the prototype. Replace only with verified product facts.
