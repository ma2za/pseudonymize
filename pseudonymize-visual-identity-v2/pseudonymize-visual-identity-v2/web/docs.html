Pseudonymize text

Send text to the API and receive content with configured sensitive entities replaced by stable pseudonyms.

Request

Create a request with the text and policy you want to apply.

curl https://api.pseudonymize.io/v1/text \
  -H "Authorization: Bearer $PZ_API_KEY" \
  -d '{ "text": "Alice lives in Munich" }'

Response

The output preserves the sentence structure while replacing detected values. Entity mappings should only be exposed according to your configured workflow.

{
  "text": "PERSON_7F2A lives in CITY_03E4",
  "entities": [
    { "type": "PERSON", "token": "PERSON_7F2A" },
    { "type": "CITY", "token": "CITY_03E4" }
  ]
}

Design principle

Technical documentation uses the same visual grammar as the product: original identifiers are neutral or danger-adjacent, transformed values use Cipher Green, and machine-readable values use mono typography.
