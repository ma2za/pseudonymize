# Security/privacy claims QA

For every visible trust/security/privacy claim:
- [ ] Is the claim present in repository/product-owner evidence?
- [ ] Does it have a source/evidence reference?
- [ ] Is it phrased no more broadly than the evidence supports?
- [ ] Does it avoid implying pseudonymization = anonymization?
- [ ] Does it avoid absolute words such as `safe`, `secure`, `anonymous`, `zero-risk` unless context technically supports them?
- [ ] Are certifications shown only when actually held and current?
- [ ] Are retention, residency, encryption and subprocessor statements verified rather than inferred?

If any answer is no: remove or narrow the claim before shipping.
