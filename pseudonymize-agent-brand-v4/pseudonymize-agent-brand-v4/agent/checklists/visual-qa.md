# Visual QA

- [ ] Hero/product demo communicates original identifier → pseudonym while surrounding content remains intact.
- [ ] Cipher green is concentrated on mapped output, mapping bond, primary CTA and true completion states.
- [ ] Sensitive identifiers are amber/subtle, not red.
- [ ] Red is reserved for failures/destructive states.
- [ ] No green gradient headline.
- [ ] No purple/cyan neon gradients, glassmorphism, shield/lock decoration, AI sparkles or stock cyber imagery.
- [ ] Ordinary radii are 4/6/8/12px; no gratuitous 24–32px cards.
- [ ] Borders define structure; shadows are uncommon.
- [ ] Product UI is denser than marketing UI.
- [ ] Data/IDs/code use mono; prose does not.
- [ ] Raw and pseudonymized values remain distinguishable without relying only on color.
- [ ] Mobile stacks source before result and remains readable.
- [ ] Keyboard focus is visible.
- [ ] Reduced-motion setting removes nonessential motion.
- [ ] Logo variant matches the surface.
- [ ] Logo has not been redrawn, rotated, glowed, animated, or placed in another decorative badge.
