# Vision: pseudonymize.io

## The Purpose
**pseudonymize.io** is the hosted service and frontend platform for the `pseudonymize` Python package. It bridges the gap between open-source functionality and enterprise-grade accessibility, offering developers a seamless, API-driven solution to anonymize and pseudonymize data at scale.

## Core Philosophy
- **Simple, Minimal, Straight to the Point:** No bloated UIs, no unnecessary complex features. Just what developers need to get their API keys and manage billing.
- **Global First:** Native support for 20 languages, ensuring global SEO dominance and localization out of the box.
- **Performance & SEO Driven:** Optimized for speed and discoverability. Built for developers by developers.

## Key Technical Pillars
1. **Hosting:** Self-hosted on Coolify / Hetzner for maximum control and cost-efficiency.
2. **Authentication:** Better Auth (Google SSO + Password).
3. **Monetization:** Stripe (Credits-based billing system).
4. **Content & SEO:** Headless CMS for multilingual, geo-optimized blog content.
5. **Separation of Concerns:** The core API (`api.pseudonymize.io`) is handled separately. This platform focuses solely on marketing, onboarding, API key management, and billing.

## Target Audience
- Data Scientists and Engineers needing scalable pseudonymization.
- Compliance teams requiring GDPR/CCPA compliant data pipelines.
- Startups and Enterprises looking to outsource PII handling.
