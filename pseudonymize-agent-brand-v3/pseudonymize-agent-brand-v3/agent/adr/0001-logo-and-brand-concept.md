# ADR 0001 — Logo and brand concept

## Decision
Use the **preserved frame / mapped identity** symbol.

## Why
The previous slash-through-P had three problems:
1. it could read as “disabled P” or prohibition
2. it expressed deletion more strongly than pseudonymization
3. it depended on a letterform pun rather than the product operation

The replacement encodes the operation directly:
- brackets: context / structure survives
- circle: original identifier
- square: pseudonym/token
- bond: relationship/mapping

It deliberately does **not** use arrows, because pseudonymization may be implemented with different mapping/reversibility semantics and the logo should not assert a technical directionality guarantee.

## Consequences
Transformation rails and mapped pairs become the main visual grammar across product, marketing and docs. This provides identity without relying on decorative illustration.
