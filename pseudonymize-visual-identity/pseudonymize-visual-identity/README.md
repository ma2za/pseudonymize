# pseudonymize.io visual identity package

This package contains an initial production-ready identity direction for pseudonymize.io.

## Core concept
Keep the structure. Lose the identity.

## Files
- BRAND-GUIDE.md — full identity system
- logo/ — SVG logo assets
- graphics/token-flow.svg — signature transformation graphic
- social/og-template.svg — social preview template
- tokens/colors.json — brand palette
- tokens/tokens.css — CSS design tokens

The logo SVGs use system fallbacks for text. For a final exported wordmark, convert type to outlines in Figma/Illustrator after locking typography.
