# 0.1.0a3

Release date: 2026-07-24

`0.1.0a3` makes dependency-free file processing a first-class workflow while preserving the
local-only core and safe reporting guarantees.

## Highlights

- Built-in TXT, Markdown, log, JSON, JSONL, and CSV processing
- Explicit format precedence and case-insensitive recognized suffixes
- Strict UTF-8 defaults, UTF-8 byte-order-mark preservation, and explicit codec support
- Stable text-offset, JSON-path, and CSV-cell locations
- Semantic structured round trips with normalized serialization
- Atomic safe-copy output and detection-only inspection
- `file` and `inspect-file` CLI commands
- Adversarial malformed-input, Unicode, large-field, symlink, race, and clean-wheel coverage
- A 99.36% branch-coverage release floor

## Breaking alpha change

The positional `0.1.0a2` file-adapter arguments are replaced by built-in selection and
keyword-only custom adapters. No compatibility shim is included. See
[Migrating to 0.1.0a3](../migration-a3.md).

## Boundaries

JSON keys are not transformed. CSV uses strict comma-separated `excel` behavior and does not
neutralize formulas. PDF, Office, OCR, NER, HTTP, delimiter sniffing, and lexical structured-file
preservation remain outside this release.
