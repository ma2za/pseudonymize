# 0.1.0rc1

Release date: 2026-08-02

`0.1.0rc1` validates the frozen dependency-free core across every supported Python version and
operating system before the first stable release.

## Highlights

- Clean installation of the built wheel on Linux, macOS, and Windows with Python 3.11 through 3.14
- Frozen compatibility checks for public names, signatures, models, enums, and deterministic tokens
- Packaging, import, bundled-file, licence, dependency, and isolated-source audits
- Portable file corpus covering BOM, newline, Unicode, JSONL, and CSV behavior
- Production-only Trusted Publishing with build-only manual rehearsals

## Compatibility

There are no public API or token-format changes from `0.1.0b1`. Only release-blocking defects may
change code during the release-candidate phase. A public redesign returns the project to beta.

## Validation feedback

External reports must use synthetic data and include the package version, operating system, Python
version, installation command, exercised workflow, and sanitized failure details. Every
release-blocking report must be resolved before `0.1.0`.

Validation is tracked in
[`Validate pseudonymize 0.1.0rc1`](https://github.com/ma2za/pseudonymize/issues/18).
