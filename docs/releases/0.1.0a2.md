# 0.1.0a2

Release date: 2026-07-23

`0.1.0a2` establishes the representation and extension contracts for local-first multimodal
processing while keeping the base package typed, dependency-free, and network-denied by default.

## Highlights

- Immutable `Document` and `ContentBlock` values with text-offset, JSON-path, and CSV-cell
  locations
- Block-aware detection backends with provenance, capability declarations, deterministic merging,
  bounds validation, and sanitized failures
- `NetworkPolicy` enforcement with separate policy and backend consent
- Safe detailed results for text, nested data, documents, and inspection
- Generic file orchestration with explicit caller-provided adapters, atomic publication, source
  protection, and no-clobber defaults
- The IP sentence-boundary regression fix, including installed-wheel coverage
- A 97.29% branch-coverage release floor and adversarial contract tests

## Breaking alpha change

The provisional text-only backend contract and `EntityBackend` are removed without a compatibility
shim. Backends now implement `detect(block, policy)` and declare `BackendCapabilities` plus
`allow_remote_processing`. See [Migrating to 0.1.0a2](../migration-a2.md).

## Deferred to 0.1.0a3

No built-in TXT, JSON, JSONL, or CSV adapter and no automatic format selection ship in this
release. File APIs require explicit adapters supplied by the caller.
