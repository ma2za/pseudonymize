# 0.1.0

Release date: 2026-08-09

`0.1.0` is the first stable release of the typed, dependency-free local processing core for text,
nested Python data, and plain or machine-readable files.

## Highlights

- Structured local detection for email addresses, phone numbers, IP addresses, IBANs, payment
  cards, URL credentials, and common secrets
- Numbered, generic, deterministic HMAC-SHA256, and redacted transformations
- Safe detailed results, reusable alias scopes, explicit policies, and extension protocols
- TXT, Markdown, log, JSON, JSONL, and CSV inspection and sanitized-copy workflows
- Python 3.11 through 3.14 support with a typed wheel and zero runtime dependencies
- Installed-wheel validation on Linux, macOS, and Windows

## Changes from 0.1.0rc1

There are no public API, runtime behavior, or deterministic token changes from `0.1.0rc1`.
Development and release tooling was updated, and documented Python examples now follow Ruff 0.16
formatting.

## Compatibility

Patch releases in the `0.1` line preserve the documented public API and token formats. Additive
capabilities may appear in minor releases. Security fixes may reject unsafe inputs and will be
called out prominently.

## Validation gate

Publication is gated on the `0.1.0rc1` validation window remaining open through
2026-08-09 09:14 UTC with every release-blocking report resolved. If the candidate requires a code
fix, a new release candidate is published instead of promoting changed code directly to stable.

Validation is tracked in
[`Validate pseudonymize 0.1.0rc1`](https://github.com/ma2za/pseudonymize/issues/18).
