# 0.1.0b1

Release date: 2026-08-01

`0.1.0b1` freezes the dependency-free core API ahead of the first stable release and documents how
to deploy it at LLM boundaries.

## Highlights

- Frozen top-level core API and documented beta-to-stable compatibility policy
- Executable gateway examples for prompts, retrieval, tool arguments, and tool output
- Expanded threat model and production deployment checklist
- Published reference performance, import-time, and wheel-size measurements
- Built-wheel execution of the documented LLM gateway example

## Compatibility

The public surface exported by `pseudonymize.__all__`, documented constructors and methods, CLI,
and token formats are frozen through `0.1.0`. A breaking core redesign returns the project to beta.
See the [compatibility policy](../compatibility.md).

## Boundaries

This beta does not add natural-language name detection, PDF or Office processing, OCR, remote
providers, or new runtime dependencies. Pseudonymization remains distinct from anonymization and
does not replace input validation, access control, retention, or provider-side privacy controls.
