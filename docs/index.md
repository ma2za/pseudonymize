# Pseudonymize

Local-first PII detection, redaction and deterministic pseudonymization for text, JSON payloads,
documents and LLM applications.

The core has no runtime dependencies and makes no network calls. It protects structured values;
it does not claim complete PII detection or GDPR compliance.

The `0.1.0a1` API is a prerelease and may change before the stable `0.1.0` release. See the
[architecture](architecture.md) and [release process](releasing.md) for the committed direction.
