# Support

Pseudonymize is maintained as an open-source alpha project on a best-effort basis.

## Usage and design questions

Open a GitHub issue using the most specific template. Include:

- the exact package version and Python version;
- the operating system;
- a minimal reproduction using synthetic data only;
- expected and actual behavior;
- relevant policy, mode, adapter, or backend configuration.

Search existing issues and the [documentation](docs/index.md) first.

## Sensitive reports

Do not open a public issue for vulnerabilities, raw-data leakage, credentials, or real personal
data. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## Scope

Only the latest prerelease is supported during alpha development. Questions about planned formats
and providers should refer to [ROADMAP.md](ROADMAP.md). The roadmap is a commitment to sequencing,
not a promise that unsupported inputs work today.
